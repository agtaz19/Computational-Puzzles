## 1. Perfect Encoding

**Released:** 2026-06-10 · [Video](https://www.youtube.com/shorts/7L_eTem1SQ4) · Code: [`1-PerfectEncoding.py`](1-PerfectEncoding.py)

A robot takes steps up, down, left, or right with probabilities $\tfrac{1}{2}$, $\tfrac{1}{4}$, $\tfrac{1}{8}$, $\tfrac{1}{8}$. What binary encoding of these instructions uses the fewest bits per instruction on average? As a challenge, prove that no encoding can do better.
