# Jane Street Puzzles

Solutions to puzzles from Jane Street's monthly puzzle series.

No puzzles have been added yet. Each new puzzle gets a numbered script (`1-ShortName.py`) and an entry below using this layout.

---

## N. Puzzle Name (`N-ShortName.py`)

**Source:** Month and year the puzzle was posted.

### Problem

A short statement of the puzzle in plain language.

### Answer

The final answer, as Jane Street asks for it.

### Reasoning

The argument for why the answer is correct, with the key steps written out.

### Code notes

What the script does, how long it takes to run, and anything to check if it is revisited.
